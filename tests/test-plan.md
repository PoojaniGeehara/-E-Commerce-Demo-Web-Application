# ShopEase – Test Plan

## 1. Project Overview

ShopEase is a demo e-commerce web application created for
Software Quality Assurance testing practice.

## 2. Testing Objective

The objective is to verify that the major functionalities of
the ShopEase application work according to the expected
requirements.

## 3. Scope

The following modules will be tested:

- Login
- Registration
- Products
- Product Details
- Shopping Cart
- Checkout
- Profile
- Logout

## 4. Testing Types

- Functional Testing
- UI Testing
- Negative Testing
- Boundary Value Testing
- Validation Testing
- Smoke Testing
- Regression Testing
- Compatibility Testing
- Responsive Testing

## 5. Test Environment

Application: ShopEase
Testing Type: Manual Testing
Browser: Google Chrome
Operating System: Windows

## 6. Test Deliverables

- Test Scenarios
- Test Cases
- Test Execution Results
- Bug Reports
- Test Summary Report

## 7. Out of Scope

- Performance Testing
- Penetration Testing
- Real Payment Processing
- Backend Testing
- Database Testing
